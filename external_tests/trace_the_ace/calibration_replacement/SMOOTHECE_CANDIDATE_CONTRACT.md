# SmoothECE replacement-calibration candidate contract

## Status

**PROSPECTIVE CANDIDATE CONTRACT — RESULT UNOBSERVED**

This contract instantiates exactly one candidate under the calibration replacement-measurement design envelope: **SmoothECE (smECE)** as defined by Błasiok & Nakkiran and pinned to the authors' reference implementation identity documented below.

This contract does **not** authorize historical M1-cal/M2-S access. Historical vectors remain sealed until all candidate-method gates pass on prospectively frozen synthetic validation.

## Candidate selection rationale

The diagnosed predecessor failure is fixed-bin cancellation: ECE-10 can average opposing local calibration residuals within a bin and thereby under-resolve a construct-faithful calibration defect.

SmoothECE is selected as the first candidate because it removes fixed histogram bins and smooths prediction residuals locally with a reflected Gaussian kernel. Candidate selection is based on the diagnosed measurement failure, not historical performance, leaderboard behavior, or convenience.

Literature/background does not itself grant authority to this candidate.

## Scientific construct

The intended construct remains binary calibration of a probability predictor:

\[
Q(p)=E[Y\mid P=p],
\qquad
C_{cal,L1}=E|P-Q(P)|.
\]

SmoothECE is **not assumed** to equal `C_cal,L1` numerically. It must earn construct fidelity prospectively.

## Adversarial fixture family

Every fixture uses prediction `P` as primitive and explicitly defines `Q(P)=E[Y|P]`. Prediction support is prospectively restricted to `[0.05,0.95]` to avoid clipping-driven artifacts.

A common deterministic prediction design is used for all fixtures:

```text
N sessions: canonical label-free Trace-the-Ace session-size distribution
within-session P coordinates: deterministic low-discrepancy quantiles on [0.05,0.95]
```

Defect amplitude is chosen deterministically to attain the declared population `C_cal,L1` target within absolute tolerance `1e-5`, before any outcomes are sampled.

Fixtures:

```text
F0  perfect calibration
    Q(p) = p

F1  global shift
    Q(p) = p + a

F2  linear tilt
    Q(p) = p + a(2p-1)

F3  smooth low-frequency defect
    Q(p) = p + a sin(2*pi*p)

F4  localized-band defect
    Q(p) = p + a * triangular(p; center=0.65, half_width=0.15)

F5  within-ECE-bin alternating defect
    Let u = frac(10p).
    Q(p) = p + a * sign(sin(2*pi*u))
    with deterministic zero-mean balancing within each legacy 0.1 ECE bin.

F6  high-frequency local defect
    Q(p) = p + a sin(20*pi*p)
```

If any chosen amplitude would move `Q(p)` outside `[0,1]`, fixture constitution fails before outcome sampling; amplitudes may not be clipped after the fact.

Construct-fidelity amplitudes:

```text
C_cal,L1 targets: 0.005, 0.010, 0.020
```

These are synthetic measurement-challenge levels only. They are not the historical practical non-inferiority margin.

## Clustered outcome generator

Finite-sample validation preserves the session as the resampling unit.

For each synthetic replicate, outcomes have Bernoulli marginals `Q(P)` with within-session dependence generated by a Gaussian copula:

```text
rho = 0.15
Z_s ~ Normal(0,1)
epsilon_si ~ Normal(0,1)
L_si = sqrt(rho) * Z_s + sqrt(1-rho) * epsilon_si
Y_si = 1[Phi(L_si) <= Q(P_si)]
```

This preserves the declared Bernoulli marginal while inducing within-session dependence.

Prospective synthetic seeds:

```text
fixture-generation master seed = 1811
bootstrap master seed          = 1812
replicates per declared scenario = 100
```

No seed may be changed after candidate performance is observed.

## Gate G_F — construct fidelity

`G_F` is conjunctive. It passes only if, using the exact population fixture objects (no sampled outcomes):

1. `F0` candidate population measurement is <= `1e-4`.
2. For every `F1..F6`, candidate population measurement is strictly positive at all three declared `C_cal,L1` targets.
3. For every `F1..F6`, candidate population measurement is strictly ordered:

```text
theta(0.005) < theta(0.010) < theta(0.020)
```

4. For `F5` and `F6`, the candidate must retain local sensitivity: at `C_cal,L1=0.010`, candidate population measurement must be at least 10% of the corresponding construct magnitude.

The 10% floor is a prospective minimum-fidelity safeguard against repeating the diagnosed ECE-10 near-erasure pathology; it is not a claim of numerical equivalence between SmoothECE and `C_cal,L1`.

If `G_F` fails, candidate evaluation stops. No estimator, bandwidth rule, fixture, or threshold tuning is authorized.

## Gate G_detect — finite-sample sensitivity and specificity

For each of `F1..F6` at `C_cal,L1=0.010`, 100 clustered synthetic datasets are sampled.

A defect is counted as detected when the 95% paired/session-cluster bootstrap lower bound for the candidate measurement exceeds the prospectively frozen `F0` 95th-percentile null critical value at the same sample geometry.

Requirements:

```text
F0 false-positive rate <= 0.10
F1..F6 detection rate >= 0.80 each
```

The null critical value is generated only from the frozen `F0` synthetic replicates, never from historical data.

If `G_detect` fails, candidate evaluation stops. No tuning is authorized.

## Gate G_U — uncertainty validity

The uncertainty procedure is the paired session-cluster percentile bootstrap:

```text
bootstrap replicates = 2000
resampling unit      = session
confidence level     = 95%
```

For each `F1..F6`, paired reference/candidate synthetic comparisons are constituted at population relative SmoothECE degradations of:

```text
R_sm = 0.00, 0.125, 0.25, 0.50
```

where

\[
R_{sm}=(\theta_C-\theta_R)/\theta_R.
\]

Candidate amplitudes are determined by deterministic population search before outcome sampling. The reference must satisfy population `theta_R >= 0.005`; otherwise that fixture family is invalid for the ratio test and candidate execution stops.

`G_U` passes only if empirical 95% interval coverage of the true `R_sm` is in `[0.90,0.99]` for every declared family/ratio cell.

If `G_U` fails, candidate evaluation stops. No bootstrap-count inflation or interval substitution is authorized.

## Gate G_decision — practical-margin decision validity

The predecessor's practical convention is preserved as **25% relative degradation**, not as the old numerical ECE margin.

Thus the candidate practical non-inferiority claim is:

\[
R_{sm}<0.25.
\]

A dataset passes NI only when:

\[
U_{95}(R_{sm})<0.25.
\]

Prospective decision behavior across the same 100 clustered replicates per cell must satisfy:

```text
true R_sm = 0.00   : NI pass rate >= 0.80
true R_sm = 0.125  : NI pass rate >= 0.80
true R_sm = 0.25   : NI pass rate <= 0.10
true R_sm = 0.50   : NI pass rate <= 0.10
```

Additionally, the reference measurement must be stably above the candidate implementation resolution:

```text
lower 95% bootstrap bound(theta_R) > 0.001
```

for at least 95% of synthetic decision replicates in every `F1..F6` cell. Failure of this denominator guard leaves the decision rule unresolved.

If `G_decision` fails, candidate evaluation stops. No threshold or margin tuning is authorized.
