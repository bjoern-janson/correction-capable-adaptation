# Decision: Scoped Program Role of G1

## Status

**PROVISIONALLY FIXED SCIENTIFIC ROLE — NO EXPERIMENT FROZEN — NO EXECUTION AUTHORIZED**

## Decision

Correction-Capable Adaptation adopts the following scoped role for its first empirical causal gate:

\[
\boxed{
G_1
=
\text{warranted evidence acquiring causal control over a separable adaptive decision}
}
\]

The current operational decomposition represents that separable adaptive decision as candidate selection:

\[
E\longrightarrow C_{\mathrm{selected}}.
\]

This is a commitment about the **empirical pathway CCA will study first**. It is not a claim that every correction-capable architecture must contain an explicit candidate-selection node.

## What is fixed

The role of `G1` is provisionally fixed as an outcome-level causal prerequisite in the current CCA decomposition:

```text
prospectively admissible evidence
        ↓
independent warrant
        ↓
causal assignment
        ↓
separable adaptive decision
        ↓
G1
```

A valid `G1` claim must concern causal movement in the warranted direction. Mere responsiveness, candidate accuracy, relation sensitivity, representation invariance, access robustness, or mechanism attribution are not substitutes.

## What is not fixed

This decision does **not** freeze:

- a candidate ontology;
- a semantic evidence set;
- an interface contract;
- a realization policy;
- a scalar G1 estimand;
- a weighting rule;
- an uncertainty procedure or threshold;
- a model or prompt;
- a benchmark;
- an ECIM contract;
- empirical execution.

Candidate selection is the current operational instantiation, not a universal architectural theorem.

## Causal boundaries

The decision preserves the non-substitutions:

\[
\boxed{G_1\neq\mathrm{CCA}}
\]

and

\[
\boxed{
G_1
\not\Rightarrow
G_2
\not\Rightarrow
\text{repeated correction}
\not\Rightarrow
\text{justified transformability}
\not\Rightarrow
\text{adaptive viability}
}
\]

`G2` remains separately identified only through direct intervention on modification:

\[
\boxed{do(M=m)\rightarrow(Y_T,Y_P)}.
\]

Selection competence must never be used as a substitute for modification competence.

## Measurement consequences

The adversarial analysis leading to this decision established the following distinctions:

```text
codebook construction          != G1
relational sensitivity         != G1
representation invariance      != G1
access robustness              != G1
candidate accuracy             != G1
mechanism/channel attribution  != G1
```

The surviving candidate treatment structure is compatible with:

```text
0A-S  semantic constitution
0A-I  interface contract
0A-R  realization policy
0B    total causal warranted-evidence control
0B-R  realization/access heterogeneity
0C    mechanism/channel attribution
```

These are measurement/identification layers supporting `G1`; they are not all part of the definition of correction-capable adaptation itself.

## Authority gained

CCA may now state:

> **The first empirical pathway studied by CCA begins by asking whether prospectively admissible, independently warranted evidence acquires causal control over a separable adaptive decision, initially instantiated as candidate selection.**

## Authority not gained

This decision does not establish that:

- G1 is positive for any tested system;
- explicit candidate selection is necessary for all correction-capable systems;
- G1 is sufficient for correction;
- a modification is effective or isolated;
- repeated correction is possible;
- justified transformability or viability increases;
- any empirical implementation is authorized.

## Next scientific boundary

The next genuinely new program-level question is the bridge from selection authority to modification competence:

\[
\boxed{G_1\rightarrow G_2?}
\]

The question must preserve the existing hard separation:

\[
\boxed{
G_2\text{ is identified by direct }do(M=m),
\text{ never by conditioning on }C_{\mathrm{selected}}.
}
\]

No implementation follows from this decision.
