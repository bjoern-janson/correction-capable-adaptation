## Provenance rule

If the clean public summary and the detailed source notebook ever disagree on a historical empirical result, the frozen source experiment/result artifacts take precedence until the public summary is corrected.

The public repository is canonical for the **program architecture and current frontier**; the source notebook remains canonical for the **detailed historical execution record**.
