# Scientific Object

## Central research question

> **Can an adaptive system increase its future viability while remaining capable of incorporating justified correction?**

## Central object

**Correction-capable adaptation** is the capacity of an adaptive system to undergo warranted, effective change while preserving the conditions required for justified future correction.

The program studies one causal pathway:

\[
\boxed{
\text{Evidence}
\rightarrow
\text{Authority}
\rightarrow
\text{Warranted selection}
\rightarrow
\text{Effective modification}
\rightarrow
\text{Protected structure}
\rightarrow
\text{Repeated correction}
\rightarrow
\text{Justified transformability}
\rightarrow
\text{Adaptive viability}
}
\]

Capability change may occur within this pathway, but capability alone does not define success.

The corresponding epistemic dependency is:

\[
\boxed{
\text{measurement}
\prec
\text{selection}
\prec
\text{modification}
\prec
\text{joint justified change}
\prec
\text{repeated correction}
\prec
\text{transformability}
\prec
\text{viability / capability}
\prec
\text{extreme-system stress tests}
}
\]

A downstream claim cannot acquire authority while a required upstream prerequisite remains unvalidated.

## Level 1 — Evidence-controlled selection

Given an independently warranted mapping

\[
E=e\mapsto C^*(e),
\]

does intervention on evidence move selection toward the candidate warranted by that evidence?

Selection variability alone is insufficient.

## Level 2 — Isolated modification

Modification effects must be identified independently of selection through direct assignment:

\[
\boxed{do(M=m)\rightarrow(Y_T,Y_P)}.
\]

Two properties are distinct:

\[
\theta_T=\text{target efficacy}
\]

and

\[
\theta_P=\text{protected-behavior interference}.
\]

Preservation is an equivalence or noninterference claim, not failure to reject a difference:

\[
H_{0,P}:|\theta_P|\ge\epsilon_P
\]

versus

\[
H_{1,P}:|\theta_P|<\epsilon_P.
\]

The tolerance \(\epsilon_P\) must be fixed prospectively.

## Level 3 — Evidence → justified modification

The Level-1 selection and Level-2 modification mechanisms must jointly support:

\[
E
\rightarrow
C^*(E)
\rightarrow
M
\rightarrow
(Y_T,Y_P).
\]

Authorization is conjunctive rather than compensatory:

\[
\boxed{
\mathrm{ADVANCE}
\iff
G_1\land G_{2T}\land G_{2P}
}
\]

A large target improvement cannot compensate for evidence-insensitive selection or unacceptable collateral interference.

## Level 4 — Repeated correction

After one valid modification, can later evidence still produce warranted correction under the same or an explicitly transformed measurement contract?

This gate is not yet operationalized.

## Level 5 — Justified transformability

Does repeated correction preserve or expand the set of warranted future transformations rather than merely achieving a local objective?

This is the empirical target of the provisional MAGIKARP theory layer. It is not yet an established metric.

## Level 6 — Adaptive viability / capability

Do correction-capable trajectories preserve or expand prospectively defined viable futures?

No viability estimand is currently frozen.

The provisional [`C_improve`](theory/C_IMPROVE.md) object is a theory-level bridge from valid feedback and justified transformation to future viability. It is not yet a measured quantity.

Capability growth is evidence at this level only when the upstream correction pathway has already been established.

## Level 7 — Extreme adaptive systems

AGI, recursive improvement, and ASI are possible stress-test regimes of the same scientific object.

They are not foundational assumptions and are not currently authorized empirical targets.

## Measurement can constitute the object

The project treats measurement as part of scientific object specification, not merely an estimator applied after the object is fully defined.

Before testing invariance or equivalence, the admissible transformation class must be specified. If a measurement representation changes which distinctions are available, it can change the identity of the object being estimated.

## Current descendant causal architecture

The provisionally fixed mechanism architecture is:

\[
\boxed{
E
\rightarrow
C_{\mathrm{selected}}
\rightarrow
M_{\mathrm{effective}}
\rightarrow
(Y_T,Y_P)
}
\]

with separate identification of:

```text
G1   evidence-conditioned warranted selection
G2T  target efficacy
G2P  protected-behavior isolation
```

No descendant experiment is currently frozen or authorized.
