# Scientific Object

## Central object

**Correction-capable adaptation** is the capacity of an adaptive system to undergo warranted change while preserving the conditions required for justified future correction.

The program studies this object through a strict causal dependency graph:

\[
\boxed{
\text{measurement}
\prec
\text{selection}
\prec
\text{modification}
\prec
\text{repeated correction}
\prec
\text{transformability}
\prec
\text{viability}
\prec
\text{capability}
}
\]

The ordering is epistemic as well as causal: a downstream claim cannot acquire authority while an upstream prerequisite remains unvalidated.

## Gate structure

### Gate M — measurement

Can the intended object be identified under a prospectively specified measurement structure?

Current frontier:

\[
G_1^{\mathrm{broad}}
\quad\text{vs.}\quad
G_1^{\mathrm{relational}}.
\]

The project must first decide what counts as evidence use before choosing an ontology designed to measure it.

### Gate S — evidence-conditioned selection

Given an independently warranted mapping

\[
E=e\mapsto C^*(e),
\]

does intervention on evidence move selection toward the candidate warranted by that evidence?

Selection variability alone is insufficient.

### Gate M′ — modification efficacy and isolation

Modification effects must be identified independently of selection through direct assignment:

\[
\boxed{do(M=m)\rightarrow(Y_T,Y_P)}.
\]

Two properties are distinct:

\[
\theta_T=\text{target efficacy}
\]

and

\[
\theta_P=\text{protected-behavior interference}.
\]

Preservation is an equivalence claim, not a failure to reject a difference:

\[
H_{0,P}:|\theta_P|\ge\epsilon_P
\]

versus

\[
H_{1,P}:|\theta_P|<\epsilon_P.
\]

The tolerance \(\epsilon_P\) must be fixed prospectively.

### Gate R — repeated correction

After one valid modification, can later evidence still produce warranted correction under the same or an explicitly transformed measurement contract?

This gate is not yet operationalized.

### Gate JT — justified transformability

Does the system retain or increase access to warranted future transformations rather than merely achieving a local objective?

This remains a theoretical candidate construct, not an established metric.

### Gate V — adaptive viability

Do correction-capable trajectories preserve or expand prospectively defined viable futures?

No viability estimand is currently frozen.

### Capability and ASI stress test

Capability growth is downstream of the preceding gates. An eventual ASI regime, if ever scientifically justified, is a stress test of the same object—not a separate project and not an assumption of this program.

## Non-compensatory authorization

Where a stage has multiple required mechanisms, authorization is conjunctive rather than compensatory. For the current descendant architecture:

\[
\boxed{
\mathrm{ADVANCE}
\iff
G_1\land G_{2T}\land G_{2P}
}
\]

A large target improvement cannot compensate for evidence-insensitive selection or unacceptable collateral interference.

## Measurement can constitute the object

The project treats measurement as part of scientific object specification, not merely an estimator applied after the object is fully defined.

Before testing invariance or equivalence, the admissible transformation class must be specified. If a measurement representation changes which distinctions are available, it can change the identity of the object being estimated.

## Current descendant causal architecture

The provisionally fixed mechanism architecture is:

\[
\boxed{
E
\rightarrow
C_{\mathrm{selected}}
\rightarrow
M_{\mathrm{effective}}
\rightarrow
(Y_T,Y_P)
}
\]

with separate identification of:

```text
G1   evidence-conditioned warranted selection
G2T  target efficacy
G2P  protected-behavior isolation
```

No descendant experiment is currently frozen.
