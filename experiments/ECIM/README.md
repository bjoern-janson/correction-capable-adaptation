# ECIM-like Descendant Architecture

## Status

**Provisional causal architecture — not yet a frozen experiment.**

The working label “ECIM” is convenient but not scientifically authoritative. The object begins with the contract, not the name.

## Causal architecture

\[
\boxed{
E
\rightarrow
C_{\mathrm{selected}}
\rightarrow
M_{\mathrm{effective}}
\rightarrow
(Y_T,Y_P)
}
\]

Three distinct estimable properties are contemplated:

\[
\theta_1=\text{evidence-conditioned warranted selection},
\]

\[
\theta_T=\text{target efficacy},
\]

\[
\theta_P=\text{protected-behavior interference}.
\]

The desired eventual configuration is conjunctive:

\[
\theta_1>0
\quad\land\quad
\theta_T\text{ satisfies a prospectively warranted effect criterion}
\quad\land\quad
|\theta_P|<\epsilon_P.
\]

No value, threshold, estimator, or sample structure is yet frozen.

## Hard design principle: direct modification assay

The modification mechanism must be identified by direct intervention:

\[
\boxed{
G_2:\ do(M=m)\rightarrow(Y_T,Y_P)
}
\]

and **not** by conditioning on whichever candidate happened to be selected under G1.

This separates:

```text
selection competence
from
modification competence
```

by design.

## G2 decomposition

```text
G2T
Does the directly instantiated modification produce the warranted target effect?

G2P
Does it keep protected behavior within a prospectively fixed equivalence tolerance?
```

Protected preservation is an equivalence claim:

\[
H_{0,P}:|\theta_P|\ge\epsilon_P
\]

versus

\[
H_{1,P}:|\theta_P|<\epsilon_P.
\]

A non-significant difference is not enough to establish preservation.

## Current blocker: G1 scientific object

Before an ontology or evidence intervention can be frozen, the project must choose between:

\[
G_1^{\mathrm{broad}}
\quad\text{and}\quad
G_1^{\mathrm{relational}}.
\]

That choice determines which candidate ontologies are admissible.
