# Mission

## One sentence

> **We study whether adaptive systems can become appropriately different—incorporating justified correction, producing effective change, preserving protected structure, and retaining the capacity for further correction—and whether this capacity explains increasingly viable adaptation and capability.**

## Central question

\[
\boxed{\textbf{Can increasing adaptive power preserve the ability to be corrected?}}
\]

## Why this project exists

Adaptive systems are often evaluated by how much they improve. That is incomplete.

A system can become more capable while also becoming harder to correct, less interpretable, more brittle, or more likely to overwrite structure that should have been preserved. Conversely, a system can remain perfectly stable by refusing to change at all.

The scientific object is therefore not improvement alone. It is **correction-capable adaptation**: warranted change that is effective, appropriately bounded, and still leaves the system open to justified future correction.

## Governing dependency

```text
measurement
  precedes selection
  precedes modification
  precedes repeated correction
  precedes transformability
  precedes viability
  precedes capability claims
```

The project does not allow downstream success to compensate for an unvalidated upstream mechanism.

## What this project is not

This repository does not begin from the assumption that:

- intelligence requires a special architectural primitive;
- self-modification is inherently beneficial;
- more capability implies more corrigibility;
- a successful output proves the system understood why it succeeded;
- ASI is imminent, inevitable, or already measured here.

ASI is treated only as a possible future **stress-test regime** if the upstream scientific gates are ever earned.

## Public commitment

The project will preserve negative results, failed constructions, measurement impossibility boundaries, and unresolved forks. A result earns only the authority its measurement and causal design identify.
