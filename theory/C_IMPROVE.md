# C_improve — Provisional Program-Level Hypothesis

## Status

```text
THEORETICAL OBJECT     PROVISIONAL
EMPIRICAL METRIC       NOT ESTABLISHED
CAUSAL ESTIMAND        NOT FROZEN
CURRENT EXECUTION      NOT AUTHORIZED
```

`C_improve` is a shorthand for the program-level hypothesis that a system's adaptive quality depends on its capacity to convert valid feedback into **justified, validated transformation that improves future viability without destroying future correctability**.

It is not yet a measured scalar and should not be used as if one exists.

## Conceptual role

The program is interested in whether the pathway

\[
E
\rightarrow
\text{authority update}
\rightarrow
\text{warranted change}
\rightarrow
\text{validated modification}
\rightarrow
\text{future viability}
\]

remains causally intact as the system changes.

A compact conceptual shorthand is:

\[
\boxed{
C_{\mathrm{improve}}
\sim
\text{capacity to convert valid feedback into increased future viability}
}
\]

subject to a critical constraint:

\[
\boxed{
\text{future gain must not be purchased by destroying the capacity for further justified correction}
}
\]

## Non-equivalences

```text
change                      ≠ improvement
capability gain             ≠ correction-capable adaptation
feedback presence           ≠ feedback use
feedback use                ≠ warranted selection
warranted selection         ≠ effective modification
effective modification      ≠ preserved correctability
local success               ≠ future viability
```

## Relationship to the maturity ladder

`C_improve` is downstream of the mechanism layers.

It cannot acquire empirical authority until the program has established, at minimum:

```text
measurement validity
→ evidence-controlled warranted selection
→ isolated modification
→ repeated correction
```

Only then can the program ask whether these properties predict or cause improved future viability.

## Relationship to MAGIKARP

MAGIKARP is a provisional theory of adaptive structure and justified transformability.

`C_improve` is the proposed bridge from that structure to downstream future viability.

Neither is currently an established metric or validated construct.

## Current implication

The present Level-0 measurement frontier cannot be skipped by defining a convenient `C_improve` score.

Measurement must earn the object before the object can be quantified.
